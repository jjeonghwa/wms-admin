# 🌐 차세대 풀필먼트 WMS (물류관리시스템)

**Node.js(Express)** 기반으로 구축된 가볍고 강력한 스마트 풀필먼트 WMS 프로토타입 프로젝트입니다. 대형 이커머스 물류 센터의 콜드체인(신선식품) 관리 및 마이크로 풀필먼트 트래킹 프로세스를 벤치마킹하여, 실시간 데이터 백업과 데이터 불변성 원칙을 최우선으로 설계한 관리자 모드 시스템입니다.

---

## 🚀 핵심 아키텍처 및 도메인 주요 기능

### 1. 이동평균법 기반의 유동적 재고 자산 가치 평가
단순 수량 카운터를 넘어, 시간에 따라 매입 단가가 계속 변동되는 실제 유통 물류의 핵심 문제를 해결했습니다. 신규 상품 입고(Inbound) 시점마다 **이동평균 단가**를 실시간 계산하여 창고에 남은 총 재고 자산 가치를 산출하며, 출고(Outbound) 시 실제 마진을 정밀하게 추적할 수 있는 구조를 제공합니다.

### 2. 하드웨어 분리형 카메라 바코드 스캐너 연동 (PDA 스캔 엔진)
글로벌 오픈소스 라이브러리(`html5-qrcode`)를 탑재하여 별도의 장비 없이 스마트폰 카메라나 웹캠을 물류 PDA 스캐너처럼 사용할 수 있습니다. 바코드를 카메라에 비추면 해시맵(Hash-Map) 구조를 통해 시스템이 해당 SKU 상품을 즉각 매칭하고 출하/진열 폼에 자동 선택해 줍니다.

### 3. 멀티 로케이션 트래킹 및 소비기한(선입선출) 제어
- **소비기한 신선도 통제**: 입고 시점의 소비기한을 오름차순으로 자동 정렬하여, 가장 임박한 재고 스태터스를 화면 최우선에 노출해 폐기율을 방지합니다.
- **로케이션 매핑**: 물류 센터 내 고정 랙(Rack Area) 구역이나 이동식 토트 바구니(Tote Box) 번호를 트랜잭션 데이터와 실시간 결합하여 이동 동선을 관리합니다.

### 4. 데이터 원장 불변성 유지 (Audit Trail)
수량을 임의로 수정하여 데이터가 오염되거나 추적이 불가능해지는 현상을 원천 차단했습니다. 모든 입/출고 흐름은 독립적인 트랜잭션 데이터(`products.json`, `history.json`)로 누적 저장되며, 현재고는 이 원장 데이터를 실시간 연산하여 도출하는 정석적인 물류 회계 방식을 채택했습니다.

### 5. RBAC 기반 운영진 권한 매니지먼트 (메뉴 분리 구조)
WMS 사용자의 권한을 통제하기 위해 별도의 운영진 관리 메뉴를 구축했습니다. 사원별 등급(총괄 매니저, 현장 매니저, 오퍼레이터)과 소속 파트(인바운드, 아웃바운드, 재고조사)에 맞는 권한 인가 및 해제가 가능합니다.

## 🛠️ 사용 기술 (Tech Stack)
- **Backend**: Node.js, Express Framework
- **Database**: JSON File-System 원장 (비동기 I/O 기반 데이터 불변 설계)
- **Frontend**: 가독성과 유지보수를 위해 HTML, CSS, JavaScript(Vanilla JS) 파일 완전 분리 설계 (구글 자동 번역기 오작동 방지 메타태그 적용)
